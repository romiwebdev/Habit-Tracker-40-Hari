# Habit Tracker 40 Hari

A 40-day habit tracker web app to build and monitor daily habits with streaks and progress, all in a single HTML file.

## Features

- Track habits across a 40-day challenge
- Streak and progress visualization
- No dependencies — single-file app
- Works offline in any modern browser

## Tech Stack

- HTML
- CSS
- JavaScript (all-in-one)

## Getting Started

Open `index.html` in a browser.
